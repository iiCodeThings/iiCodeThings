# 会话菜单与 `/new-session`

日期：2026-09-08

桌面会话行图标过多，挡住标题。「新对话」按钮改为输入框命令。

## 1. 目标

- 桌面和窄屏：每条会话标题旁只留一颗**三横线**按钮，点开菜单操作该会话。
- 去掉所有「新对话」按钮。发送以 `/new-session` 开头的内容时新建会话，可选标题。

## 2. 明确不做

- 不改后端建会话默认标题（仍是「新对话」），不改「标题仍为新对话则首次消息自动命名」。
- 不增加其它斜杠命令。
- 不把 `/search` 接进主界面。
- 不改置顶/重命名/分享/AI 标题/删除的接口语义。

## 3. 会话菜单

- 桌面与窄屏同一套：标题 + 时间 + 三横线（现有 `menu` 图标），`aria-label`「会话操作」。
- 菜单项与现在相同：置顶或取消置顶、重命名、分享会话、用 AI 生成标题、删除。
- 点菜单项或点菜单外关闭。不再渲染六个并排图标，不再用「更多」文字。
- `sessionActionsMode` 恒为菜单；不再按窄屏切换 icons/menu。

## 4. 去掉「新对话」

- 删除左栏和窄屏顶栏的「新对话」按钮。
- 窄屏顶栏只留：汉堡、当前标题。
- 空聊天占位改为：`选择左侧会话，或发送 /new-session 开始`。

## 5. `/new-session`

发送时对输入正文 `trim()` 后判断：若以 `/new-session` 开头（大小写敏感）：

- **不**调用发消息接口，**不**上传附件，**不**要求已选模型。
- 标题 = 去掉前缀 `/new-session` 后再 `trim()` 的剩余。空 → 保持默认「新对话」；非空 → `PATCH` 为该标题（截断到 128 字，与现有改名一致）。
- 然后：`POST /api/sessions`、选中该会话、清空输入框、关闭窄屏抽屉、若当前不在 `/` 则回到 `/`。
- 例：`/new-session` 与 `/new-session   ` → 标题「新对话」。`/new-session 韦伯笔记` → 标题「韦伯笔记」。`/new-sessionfoo` → 标题「foo」（仍算命令）。

普通消息（不以该前缀开头）发送逻辑不变，仍要选模型。

## 6. 测试

- `parseNewSessionCommand(raw)`：非命令返回 `null`；命令返回 `{ title: string | null }`（`null` 表示用默认「新对话」）。
- 会话模板只有 `session-actions menu` + `name="menu"`，没有 `session-actions icons`、没有「新对话」按钮文案。
- 现有前端单测仍通过。
